## Описание проекта

Stellar Burger — это веб-приложение для заказа бургеров с космической тематикой. Проект реализован с использованием React, Redux Toolkit, React Router и TypeScript. Включает в себя авторизацию, управление состоянием, работу с API, ленту заказов в реальном времени и личный кабинет пользователя.

## Быстрый старт

### Предварительные требования
- Node.js (версия 16 или выше)
- npm

### Установка и запуск

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/konovalov-nv/stellar-burgers.git
cd stellar-burgers
```
2. **Установите зависимости:**
```bash
npm install
```
3. **Создайте файл .env в корне проекта:**
```bash
BURGER_API_URL=https://your-api-url.com
```
Сама ссылка находится в файле `.env.example`.

4. **Запустите приложение в режиме разработки:**
```bash
npm run start
```
5. **Откройте браузер по адресу:**
```bash
http://localhost:4000
```
6. **Сборка для продакшена:**
```bash
npm run build
```
Собранные файлы будут находиться в папке dist/.

## Основной функционал

### Авторизация и профиль
- Регистрация и вход в систему
- Редактирование данных пользователя с сохранением в API
- Валидация форм и обработка ошибок
- Защищённые маршруты для авторизованных пользователей
- Активная навигация с подсветкой текущего маршрута

### Конструктор бургера
- Drag-and-drop ингредиентов
- Подсчёт стоимости бургера
- Сборка из булок, начинок и соусов
- Создание заказа (только для авторизованных)

### Лента заказов
- Реальное время через WebSocket
- Отображение всех заказов
- Статистика (всего заказов, за сегодня)
- Доступна всем пользователям

### История заказов
- Только для авторизованных пользователей
- Статусы заказов: "Отменён", "Готовится", "Выполнен"
- Обновление в реальном времени

### Модальные окна
- Просмотр ингредиентов (`/ingredients/:id`)
- Детали заказа (`/feed/:number`, `/profile/orders/:number`)
- Закрытие по крестику или клику на оверлей

## Маршруты приложения

### Публичные маршруты (доступны всем пользователям)

| Маршрут | Компонент | Описание |
|---------|-----------|----------|
| `/` | `ConstructorPage` | Главная страница с конструктором бургера |
| `/feed` | `Feed` | Лента всех заказов в реальном времени |
| `/feed/:number` | `Modal` + `OrderInfo` | Детали заказа из ленты (модальное окно) |
| `/ingredients/:id` | `Modal` + `IngredientDetails` | Детали ингредиента (модальное окно) |

### Защищённые маршруты (только для авторизованных пользователей)

| Маршрут | Компонент | Описание |
|---------|-----------|----------|
| `/login` | `Login` | Страница входа в систему |
| `/register` | `Register` | Страница регистрации нового пользователя |
| `/forgot-password` | `ForgotPassword` | Восстановление пароля |
| `/reset-password` | `ResetPassword` | Сброс пароля |
| `/profile` | `Profile` | Личный кабинет пользователя |
| `/profile/orders` | `ProfileOrders` | История заказов пользователя |
| `/profile/orders/:number` | `Modal` + `OrderInfo` | Детали заказа из истории (модальное окно) |

### Обработка ошибок

| Маршрут | Компонент | Описание |
|---------|-----------|----------|
| `*` | `NotFound404` | Страница 404 для несуществующих маршрутов |

## Технологический стек

### Frontend
- **React** — библиотека для построения пользовательских интерфейсов
- **TypeScript** — типизированный JavaScript
- **Redux Toolkit** — управление состоянием приложения
- **React Router DOM v6** — маршрутизация
- **WebSocket** — реальное время для ленты заказов
- **CSS Modules** — стилизация компонентов

### Тестирование
- **Jest** — юнит-тесты
- **Playwright** — интеграционные и E2E тесты
- **Redux Mock Store** — тестирование Redux

### Инструменты
- **Webpack** — сборка проекта
- **ESLint** — линтинг кода
- **Prettier** — форматирование кода
- **Storybook** — документация компонентов
